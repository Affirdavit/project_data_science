# 📚 Project Data Science

Welcome to my data science journey.

This repository serves as a comprehensive log of my learning process, showcasing various projects and analyses I've undertaken to solidify my understanding of data science concepts.

---

## 🧠 Projects Overview

Each folder within this repository represents a distinct project, complete with Jupyter notebooks, datasets, and relevant analyses. Here's a brief overview:

1. **NYC Airbnb Market**
   An exploration of Airbnb listings in New York City, focusing on pricing trends, location analysis, and occupancy rates.

2. **Titanic Survival Prediction**
   A classic machine learning problem where I predict passenger survival on the Titanic using classification algorithms.

3. **Diamond Price Analysis**
   An analysis of diamond prices based on attributes like carat, cut, color, and clarity, employing regression techniques.

4. **Bank Marketing Campaign**
   An examination of a bank's marketing campaign data to predict customer subscription to a term deposit.

5. **AI Job Market 2025**
   A forward-looking analysis of the AI job market, identifying trends and forecasting future demand.

## 🚀 Getting Started

To replicate or build upon these projects:

1. Clone this repository:

   git clone [https://github.com/Affirdavit/project\_data\_science.git](https://github.com/Affirdavit/project_data_science.git)

2. Navigate into the project directory:

   cd project\_data\_science

3. Install the required dependencies:

   pip install -r requirements.txt
